# ⚡ Quick Start Guide

## 🚀 Start in 30 Seconds

### 1. Start Backend
```bash
cd leet/codeash/backend
npm start
```
✅ Server running on http://localhost:5000

### 2. Start Frontend
```bash
cd leet/codeash
npm run dev
```
✅ App running on http://localhost:5177

### 3. Open Browser
```
http://localhost:5177
```
