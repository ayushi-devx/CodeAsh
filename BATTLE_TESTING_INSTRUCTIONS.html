🎮 Battle Arena Testing Guide

Complete step-by-step instructions for testing multiplayer battles

🚨 CRITICAL: Authentication Required!

You MUST login in BOTH browsers before testing!
Without login, you'll get "401 Unauthorized" errors.

🖥️ Main Browser (Player 1)

  • Open http://localhost:5174
  • Login with Google (account1@gmail.com)
  • Click "Game Room" in navbar
  • Click "Room Match"
  • Click "Create Room"
  • Select difficulty (Easy/Medium/Hard)
  • Click "Create Room"
  • Copy room code (e.g., "ABC123")
  • Wait for opponent...

🕵️ Incognito Browser (Player 2)

  • Open incognito window
  • Go to http://localhost:5174
  • Login with DIFFERENT account!
  • Click "Game Room"
  • Click "Room Match"
  • Click "Join Room"
  • Enter room code from Player 1
  • Click "Join Room"
  • Battle starts! 🎮

✅ What You Should See (Success)

  • Both browsers show Battle Arena
  • Same problem displayed in both
  • Timer starts at 45:00
  • Can write code in Monaco editor
  • Can run tests and see results
  • Real-time opponent status updates
  • Can submit solution
  • Winner screen appears
  • ELO rating changes shown

❌ Common Mistakes

  • Not logging in before testing
  • Using same account in both browsers
  • Forgetting to copy room code
  • Backend not running (port 5000)
  • Frontend not running (port 5174)
  • MongoDB not connected

💡 Pro Tips

  • Use Google Login: Faster than email signup
  • Keep room code ready: Copy it immediately after creation
  • Start with Easy: Test the flow with easy problems first
  • Check backend logs: See real-time events in terminal
  • Position windows side-by-side: Better testing experience
