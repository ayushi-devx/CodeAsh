# 🚀 Quick Start - Streak Dashboard

## Start the Application

### Terminal 1 - Backend
```bash
cd leet/codeash/backend
npm start
```

### Terminal 2 - Frontend
```bash
cd leet/codeash
npm run dev
```

## Access Streak Dashboard

1. Open browser: `http://localhost:5173`
2. Login with your account
3. Click **"Streak"** in the navigation bar
4. View your activity dashboard!

## Build Your Streak

### Day 1
- Solve any problem
- Your streak starts at 1 🔥

### Day 2 (Next Day)
- Solve another problem
- Streak increases to 2 🔥🔥

### Keep Going!
- Solve at least 1 problem per day
- Watch your streak grow
- Track progress on the heatmap

## What You'll See

### Streak Cards
- **Current Streak**: Your active consecutive days
- **Longest Streak**: Your best achievement
- **Total Active Days**: Unique days with submissions

### Activity Heatmap
- 52 weeks of activity visualization
- Green squares = more submissions
- Hover to see details

### Statistics
- Problems solved by difficulty
- Submission acceptance rate
- Language usage breakdown
- Recent solved problems

## Tips

✅ Solve problems daily to maintain streak
✅ Try different languages to diversify stats
✅ Check heatmap to identify inactive periods
✅ Aim to beat your longest streak record

## Migration (For Existing Users)

If you have existing submissions, run this once:
```bash
cd leet/codeash/backend
node migrateUserStreaks.js
```

This initializes streak data from your submission history.

---

**That's it! Start coding and build your streak! 🔥**
