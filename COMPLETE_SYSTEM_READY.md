## 🚀 How to Use

### Start Servers
```bash
# Terminal 1 - Backend
cd backend
npm start

# Terminal 2 - Frontend
npm run dev
```

### Access Application
- Frontend: http://localhost:5175
- Backend: http://localhost:5000

### Solve Problems

#### Method 1: On CodeAsh
1. Go to Problems section
2. Click any problem
3. Write code in editor
4. Click "Run" to test
5. Click "Submit" to submit
6. View results instantly

#### Method 2: External Sites
1. Go to Problems section
2. Click LeetCode/GFG icon
3. Solve on external platform
4. Come back to track progress
